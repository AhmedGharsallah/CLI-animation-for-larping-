# Matrix Rain

A Matrix-style falling character effect for your terminal. Pure Python, no dependencies.

## Run it

```bash
python3 matrix.py
```

Press `Ctrl+C` to stop.

## Requirements

- Python 3.6+
- A terminal that supports ANSI escape codes

## Customize

- `CHARS` — the characters used
- `COLOR_PALETTE` — the colors for each drop
- `time.sleep(0.05)` — fall speed (lower = faster)
